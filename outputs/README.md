# Curated Analysis Outputs

These CSV files are generated by `python/02_eda_rfm.py` and intentionally committed so reviewers can inspect the project's actual results without downloading the full raw dataset.

| File | Purpose |
|---|---|
| `kpi_summary.csv` | Executive KPI snapshot |
| `annual_sales.csv` | Annual revenue, orders, customers, AOV, YoY growth |
| `monthly_sales.csv` | Monthly revenue, orders, customers, AOV, MoM growth |
| `category_performance.csv` | Category-level revenue and mix |
| `metal_performance.csv` | Metal-level revenue and mix |
| `gem_performance.csv` | Gemstone-level revenue and mix |
| `price_band_performance.csv` | Revenue and order mix by price band |
| `rfm_segment_summary.csv` | Customer and revenue share by RFM segment |
| `top_products.csv` | Top 100 products by revenue |
| `top_customers.csv` | Top 25 customers by lifetime value |
| `data_quality_summary.csv` | Structural repair, missingness, and duplicate audit |

Detailed customer-level RFM output and locally generated chart images are written to `outputs/generated/` and ignored by Git to keep the repository lightweight.

# Curated Analysis Outputs

These CSV files are generated by `python/02_eda_rfm.py` and committed so reviewers can inspect the project's actual analytical results without first reproducing the pipeline.

| File | Purpose |
|---|---|
| `kpi_summary.csv` | Executive KPI snapshot |
| `annual_sales.csv` | Annual revenue, orders, customers, AOV, and YoY growth |
| `monthly_sales.csv` | Monthly revenue, orders, customers, AOV, and MoM growth |
| `category_performance.csv` | Category-level revenue and mix |
| `metal_performance.csv` | Metal-level revenue and mix |
| `gem_performance.csv` | Gemstone-level revenue and mix |
| `price_band_performance.csv` | Revenue and order mix by price band |
| `rfm_segment_summary.csv` | Customer and revenue share by RFM segment |
| `top_products.csv` | Top 100 products by revenue |
| `top_customers.csv` | Top 25 customers by lifetime value |
| `data_quality_summary.csv` | Structural repair, missingness, and duplicate audit |

The detailed customer-level RFM working output is generated under `outputs/generated/customer_rfm.csv`. A validated copy is also published to `data/customer_rfm.csv` by the GitHub Actions sync workflow so Power BI reviewers can use the complete customer table directly from the repository.

Likewise, the full cleaned working fact table is generated at `data/processed/jewelry_clean.csv`, while the validated Power BI-ready copy is committed as `data/jewelry_clean.csv`.

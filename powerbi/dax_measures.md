# Power BI DAX Measure Library

Assumed tables:

- Fact: `jewelry_sales`
- Date: `DimDate`
- Customer snapshot: `CustomerRFM`

Recommended display folders are shown by section.

---

# 01 Executive KPIs

```DAX
Gross Sales =
SUM ( jewelry_sales[line_revenue] )
```

```DAX
Orders =
DISTINCTCOUNT ( jewelry_sales[order_id] )
```

```DAX
Customers =
DISTINCTCOUNT ( jewelry_sales[user_id] )
```

```DAX
Products =
DISTINCTCOUNT ( jewelry_sales[product_id] )
```

```DAX
Units =
SUM ( jewelry_sales[quantity] )
```

```DAX
Transaction Lines =
COUNTROWS ( jewelry_sales )
```

```DAX
Average Order Value =
DIVIDE ( [Gross Sales], [Orders] )
```

```DAX
Average Item Price =
AVERAGE ( jewelry_sales[price] )
```

```DAX
Items per Order =
DIVIDE ( [Units], [Orders] )
```

# 02 Customer & Retention

The first two measures below are dynamic within the active fact-table filter context.

```DAX
Repeat Customers =
COUNTROWS (
    FILTER (
        VALUES ( jewelry_sales[user_id] ),
        CALCULATE ( DISTINCTCOUNT ( jewelry_sales[order_id] ) ) > 1
    )
)
```

```DAX
Repeat Customer Rate =
DIVIDE ( [Repeat Customers], [Customers] )
```

# 03 Merchandising

```DAX
Category Revenue Share =

    [Gross Sales],
    CALCULATE ( [Gross Sales], ALL ( jewelry_sales[category_name] ) )
)
```

```DAX
Product Revenue Rank =
RANKX (
    ALLSELECTED ( jewelry_sales[product_id] ),
    [Gross Sales],
    ,
    DESC,
    DENSE
)
```

```DAX
Premium Sales =
CALCULATE (
    [Gross Sales],
    jewelry_sales[price] >= 250
)
```

```DAX
Premium Revenue Share =
DIVIDE ( [Premium Sales], [Gross Sales] )
```

# 04 Time Intelligence

```DAX
Sales Previous Month =
CALCULATE (
    [Gross Sales],
    DATEADD ( DimDate[Date], -1, MONTH )
)
```

```DAX
MoM Sales Change =
[Gross Sales] - [Sales Previous Month]
```

```DAX
MoM Sales % =
DIVIDE ( [MoM Sales Change], [Sales Previous Month] )
```

```DAX
Sales Previous Year =
CALCULATE (
    [Gross Sales],
    SAMEPERIODLASTYEAR ( DimDate[Date] )
)
```

```DAX
YoY Sales Change =
[Gross Sales] - [Sales Previous Year]
```

```DAX
YoY Sales % =
DIVIDE ( [YoY Sales Change], [Sales Previous Year] )
```

```DAX
Rolling 3M Sales =
CALCULATE (
    [Gross Sales],
    DATESINPERIOD (
        DimDate[Date],
        MAX ( DimDate[Date] ),
        -3,
        MONTH
    )
)
```

# Date Table

```DAX
DimDate =
ADDCOLUMNS (
    CALENDAR (
        MIN ( jewelry_sales[order_date] ),
        MAX ( jewelry_sales[order_date] )
    ),
    "Year", YEAR ( [Date] ),
    "Month Number", MONTH ( [Date] ),
    "Month", FORMAT ( [Date], "MMM" ),
    "Year Month", FORMAT ( [Date], "YYYY-MM" ),
    "Year Month Sort", YEAR ( [Date] ) * 100 + MONTH ( [Date] ),
    "Quarter", "Q" & FORMAT ( [Date], "Q" )
)
```

After creating the table:

1. Mark `DimDate` as the model's date table using `DimDate[Date]`.
2. Sort `DimDate[Year Month]` by `DimDate[Year Month Sort]`.
3. Create the relationship `DimDate[Date]` **1 → *** `jewelry_sales[order_date]`.

# Recommended Formatting

| Measure | Format |
|---|---|
| Gross Sales / RFM Revenue / At Risk Revenue | Currency, 0–2 decimals; display units Millions on cards |
| Average Order Value / Average Item Price / Average Customer Value | Currency, 2 decimals |
| Orders / Customers / Products / Units | Whole number |
| Repeat Customer Rate | Percentage, 1 decimal |
| RFM Customer Share / RFM Revenue Share | Percentage, 1 decimal |
| Category Revenue Share / Premium Revenue Share | Percentage, 1 decimal |
| MoM Sales % / YoY Sales % | Percentage, 1 decimal |
| Missing-rate measures | Percentage, 1 decimal |

## Important RFM filter note

`CustomerRFM` is a fixed RFM snapshot calculated relative to the maximum transaction date in the dataset. Do not make its segment visuals appear to be dynamically recalculated by a date slicer unless you explicitly rebuild RFM as a dynamic model. For this portfolio report, keep the RFM page clearly labeled **Snapshot RFM Segmentation**.
